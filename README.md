🎓 Welcome to My friend English training space

An interactive, single-file Progressive Web Application (PWA) designed to help kids, teenagers, and educators practice English from Pre-A1 to B1 aligned with the Cambridge English Scale and CEFR Can-Do Statements.

🌟 Key Features

Multi-Level Learning (Pre-A1 to B1):

Pre-A1 (Starters): Basic words, colors, numbers, and classroom expressions.

A1 (Movers): Daily routines, prepositions of place, and basic questions.

A2 (Flyers / Key): Past experiences, simple past, and modal verbs.

B1 (Preliminary): Expressing opinions, future plans, and logic reading tasks.

Cambridge "Can-Do" Objectives: Clear performance goals for each level.

Interactive Flashcards: Built-in Text-to-Speech audio for authentic English pronunciation and flip-card translation.

Practice Quizzes: Instant score calculation and feedback.

Teacher & Student Access Roles:

Student Mode: Clean interface dedicated strictly to practice, learning objectives, flashcards, and quizzes.

Teacher Mode (PIN Protected): Administrative panel allowing educators to create new vocabulary cards and quiz questions on the fly.

Mobile Ready & Offline Capable (PWA): Can be installed directly onto iOS and Android home screens and used without an active internet connection.

🚀 How to Use / Run the Project

No complex installations, Node.js packages, or database servers are required!

1. Opening Directly in Browser

Download or save the index.html file to your computer or mobile device.

Double-click index.html to open it in any modern browser (Google Chrome, Microsoft Edge, Safari, Firefox).

2. Logging In

Student Login: Select Student Access, enter your name, and start practicing immediately.

Teacher Login: Select Teacher Access, enter the default security PIN (1234), and unlock the + Add Custom Activities dashboard.

📱 Mobile Installation Guide (PWA)

Android (Chrome / Edge)

Open the website or index.html in Chrome.

Tap the Three Dots (⋮) in the top-right corner.

Select "Add to Home screen" or "Install app".

iPhone & iPad (Safari)

Open the website link in Safari.

Tap the Share Button (⎋) at the bottom of the screen.

Scroll down and tap "Add to Home Screen".

🛠️ Technology Stack

HTML5 & CSS3

React 18 (Standalone via Babel JS)

Tailwind CSS (Utility-first styling)

Font Awesome 6 (Icons)

Browser Web Speech API (Native audio pronunciation)

🔒 Security & Data Persistence

Custom vocabulary and quiz questions created in Teacher Mode are automatically saved in the browser's Local Storage (localStorage), ensuring your custom content remains saved even when refreshing or closing the browser.

Default access PIN for Teacher Mode: 1234.
